# Poses de Nico Maré

Quatro PNGs transparentes, com quadros de 768 × 768 pixels. A arte foi recortada sem redimensionamento. A base de cada pose fica em y=736; o desenho está centralizado horizontalmente.

`nico_poses.png` reúne os quatro quadros em uma linha: parado, corrida, salto e espada. Dimensões: 3072 × 768 pixels.

São poses estáticas para o protótipo, não ciclos completos de animação. Use cada pose conforme o estado do jogador; não reproduza a linha inteira como uma animação de corrida. O colisor deve ser independente da imagem. A centralização visual pode precisar de ajuste por pose ao integrar, especialmente no ataque, por causa da espada estendida.

O arquivo original em Downloads foi preservado. Nenhuma lógica do jogador foi alterada.
